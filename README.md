# jinjiancheng-family-skill

## What This Is

This repository contains a system-first family and parenting advisor skill inspired by 金渐成's family-related writing. It is built to help users judge family issues by looking at household structure, couple alignment, age stage, and long-term stewardship before jumping to tactics.

## What Was Distilled

- 家庭关系
- 育儿教育
- 婚姻经营
- 伴侣协作
- 家庭传承

## When To Use

Use this skill when the question is about how a family runs over time, not just how to fix one moment.

- 家庭关系是否失衡
- 育儿教育怎么抓重点
- 婚姻经营怎么减少内耗
- 伴侣协作怎么统一口径和分工
- 家庭传承怎么理解长期建设和对子女期待

## When Not To Use

Do not use this skill as a substitute for professional help in these areas:

- 医疗
- 心理诊断
- 法律
- 投资配置

## Repository Structure

- `SKILL.md`: the operational skill entrypoint
- `references/research/`: distilled research by topic
- `references/sources/`: local corpus notes and source method
- `examples/demo-conversation.md`: short example interactions
- `LICENSE`: repository license

## Installation

You can install this repository in two simple ways:

1. Copy the repository folder into your local skills directory and load it there as a standalone skill.
2. Keep it as a reference repo and reuse its `SKILL.md`, research notes, and examples when building or adapting related family and parenting skills.

At runtime, the entrypoint is `SKILL.md`, and the skill should be addressed as `jinjiancheng-family-perspective`.

## Sources And Method

The primary source was local historical articles from the user's offline corpus, not generic web summaries. The repo distills recurring patterns across those articles into a reusable decision framework for family relationships, parenting, couple coordination, and long-term family stewardship.
